# 版本记录

## 2.2.2 — 2026-10-31

- 保留三页布局，在“详细信息”顶部新增打开日志文件夹和复制脱敏诊断摘要。摘要按固定白名单生成，仅含版本、运行时、依赖存在性、完整性及操作状态；不复制 IP、账号、密码、文件路径或原始日志，也不执行网络探测或写入配置。
- 传输页在扫描、上传与等待期间每秒显示本轮已耗时。成功、部分完成、失败与停止结果均保存总耗时，重新打开后仍能查看最近结果。
- rclone 参数、并发、备份内容判定、失败重试与版本保留规则沿用 2.2.1。
- 新增脱敏摘要白名单测试，并检查成功、停止和部分失败结果的耗时保存；更新默认/小窗口的合成界面预览。

本轮完整公开测试入口共 165 项断言通过，全部使用本机合成 FTP、生成文件和模拟账号。没有访问真实手机、改写用户配置或部署。本轮不重复既有挂载与状态写入故障注入验证；真实手机备份与远端逐字节校验不在本机结果之内。

## 2.2.1 — 2026-10-31

在 DeepSeek 完善的 2.2 基础上审查与修正备份边界，保留已有的三页界面、并发上传、按对象确认成功和部分进度保存。

- 仅在明确的 550/553 临时改名拒绝时使用直接写入兼容重试；EOF、连接拒绝与普通上传权限错误维持原有失败分类。
- 为上传临时文件增加本工具专属后缀。清理范围同时匹配当前源文件、标记与文件名；保留不明 `.partial`、其他备份源的临时项及本地真实同名文件。
- 本地配置与状态文件更新保留旧记录及回滚路径，避免替换失败后先删除旧文件。
- 先解析原始 rclone JSON，再对展示内容遮罩密码，避免密码恰好为 JSON 字段名或成功关键词时破坏对象级确认。
- 拒绝源路径祖先中的 junction/符号链接，阻止借助目录别名绕过工具目录备份排除。
- 新增本机合成审查夹具与可复现入口，公开当前源码、测试与合成截图。
- 将旧工具、旧脚本、私人部署文档和旧发布产物归档保留；公开发布包不含个人配置、日志、离线安装包或历史部署记录。

本轮普通夹具共 141 项断言通过，另有状态写入回退的 5 项编译期故障注入通过，并复测两类故障 FTP 场景。本机验证仅使用 localhost 合成 FTP、生成文件与合成账号；未运行真实手机备份。详细步骤见 [测试指南](testing.md)。
